# 第一版設計

目的：用最少部署依賴，交付能真正打完一局的台灣十六張單機遊戲。

採原生 JavaScript ES Modules 與靜態網頁；不使用外部 API、後端或 LLM。綠色毛氈牌桌、木色桌框、米白牌面與金色操作重點；主要畫面就是四人牌桌。

狀態分為 discard、response、over。每張實體牌有獨立 id，所有牌只存在於牌牆、暗手、牌河、花牌或副露其中一处；pending 與 lastDiscard 僅引用，不算額外實體牌。副露與搶槓仲裁完成前不移動被搶牌。非法操作在修改前驗證。

每次畫面動作使用相同引擎函式；電腦 850ms 後行動，使用者決策無倒數。對話框開啟時暫停電腦，關閉後繼續。所有資料留在目前分頁；重新整理重開，不接帳號、排行或雲端存檔。

牌型以五面子加一對為準；本版桌規與計分限制詳見 README 與遊戲內玩法說明。手機手牌橫向捲動，牌河各有獨立可捲動區域。

驗證重點：胡牌判定、反方向吃牌拒絕、胡碰優先、槓補牌、搶槓、付款守恆、144張實體牌守恆與完整局終止。
