# 本機存檔與公開發布

依使用者提供的分享對話實作 V1：無帳號、無後端、無付費 API，沿用 GitHub Pages 正式網址。

- SaveGameService 單一入口，保存完整引擎狀態及 saveVersion、gameVersion、createdAt、lastSavedAt、gameId。
- 每次引擎操作完成後、顯示提示前寫入，避免動畫中離開漏存。恢復時不重播引擎操作或重複付款。
- 開局擲骰可恢復同一組骰子與牌牆；接牌選擇、聽牌鎖手、吃後禁打、搶槓胡等待均保留。
- 有存檔時先選繼續或新遊戲，新遊戲二次確認；無存檔直接開局。
- 單局結算仍可續桌，整桌結束才清除 active save。
- 驗證結構、版本、144 張實體牌身分與唯一性；無效存檔不載入。儲存錯誤須明示，遊戲仍可玩。
- 多分頁採寫入前版本比對及 storage 通知，舊分頁停止操作並要求重新載入，避免悄悄覆蓋。
- 發布產物使用內容雜湊資源路徑，正式連結不需 ?v=；顯示產品版本及啟動失敗說明。
- 驗證：實際引擎對局存讀後繼續一致、錯誤存檔、儲存失敗、刷新/重開續玩、跨分頁、桌面與手機橫向、公開檔案部署一致性。
