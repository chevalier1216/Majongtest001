# 青竹牌室 · Majongtest001

台灣十六張麻將單機練習。你對三位電腦；繁體中文介面，使用提供的麻將牌面參考圖。

## 開始玩

網站版：https://majongtest001.meimeip.chatgpt.site/ （部署網址若與此不同，以交付訊息為準。）

本機版：安裝 Python 3，於專案目錄執行 `python -m http.server 8080 --directory dist`，開啟 `http://localhost:8080`。
也可使用任何靜態網頁伺服器提供 `dist/`。ES Modules 需要 HTTP，請勿直接雙擊 HTML。

無 npm 安裝、無 LLM、無外部 API、無連線對手。牌局由瀏覽器本機運算；首次成功載入及離線快取完成後，可離線繼續使用。積分在目前分頁內保留，重新整理會重開一桌。

## 操作

- 點手牌選取，再按「打出」；雙擊直接出牌。
- 聚焦手牌後，以左右方向鍵選牌、Enter 出牌。
- 吃碰槓胡機會不設倒數；選擇行動或「過」。
- 牌局結束可看結算、檢查四家手牌，或進入下一局。

## 實作規則與界線

- 144 張：萬、索、筒各 36，字牌 28，花牌 8。參考圖的紅五不使用；普通五每種四張。
- 閒家 16 張、莊家 17 張；花牌不算手牌，從牌尾補牌。
- 一般胡牌為五組面子加一對將；依已副露組數減少暗手張數。
- 吃僅限上家；胡 > 碰／槓 > 吃；同等碰槓按出牌者下家起算。
- 支援明槓、暗槓、加槓、搶加槓、一炮多響。
- 過水：放棄接牌胡後，直到自己再次摸牌才可接牌胡。
- 固定保留尾端 16 張，槓不加留；無足夠補牌則流局。
- 莊家胡／流局連莊；非莊家胡則換莊。此為連續練習，未設定完整四風圈終局。
- **練習積分而非台數結算**：放銃每位贏家 100 分；自摸三家各付 100 分。
- 未做七搶一、八仙等特殊花胡、台數計算、包牌與各地自訂規則。花牌只展示。
- 電腦使用自身手牌的組合評分，偏好面子與搭子；不讀其他玩家暗手作出牌決策。洗牌使用種子亂數，適合單機測試，不作競技或賭博使用。

基本牌型參考：[台灣麻將](https://zh.wikipedia.org/wiki/台灣麻將)、[和牌](https://zh.wikipedia.org/wiki/和牌)。差異以上述本版桌規為準。

## 檔案

- `dist/engine.mjs`：純牌局狀態機、胡牌檢查、AI、積分。
- `dist/app.mjs`：畫面、使用者操作、電腦節奏、可選音效。
- `dist/style.css`：自適應牌桌與牌面 sprite。
- `dist/assets/tiles.png`：使用者提供的原始參考圖，未修改；CSS 取用牌面區域。該素材來源與授權未另行核實，不包含於程式碼 MIT 授權聲明。
- `dist/sw.js`：離線快取。
- `tests/engine.test.mjs`：規則與完整對局測試。

## 驗證

Node.js 20 以上執行 `node --test tests/engine.test.mjs`。
測試涵蓋五面子胡牌、張數守恆、非法操作、30 局種子對局、吃牌方向、胡牌優先、明槓、搶槓、自摸付款、流局。
未執行真實瀏覽器視覺／端對端驗證；WebMCP 是漸進增強，無相容環境時不影響一般遊玩。
